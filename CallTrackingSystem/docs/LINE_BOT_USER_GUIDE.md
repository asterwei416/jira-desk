# LINE Bot 使用者手冊

## 功能概述

LINE Bot 讓您直接在 LINE 對話視窗中回報問題，無需開啟網頁。

### 三大功能

1. **網頁端綁定 LINE 帳號** - 在個人設定頁面完成綁定
2. **LINE Bot 對話式回報** - 在 LINE 中透過引導完成問題回報
3. **接收即時通知** - 處理人員收到新回報單 Flex Message

---

## 1. 綁定 LINE 帳號

### 步驟

1. 使用瀏覽器登入系統（需為 **職員** 或 **管理員** 角色）
2. 前往「個人設定」頁面（通常在右上角選單）
3. 找到「LINE 官方帳號綁定」區塊
4. 點擊「綁定 LINE 帳號」按鈕
5. 系統會開啟 LINE Login 頁面，點擊「同意」授權
6. 授權完成後自動返回個人設定頁面，顯示「綁定成功」訊息

### 注意事項

- ⚠️ **訪客角色** 無法綁定 LINE（請聯絡管理員變更角色）
- ⚠️ 一個 LINE 帳號只能綁定一個系統帳號
- ✅ 綁定成功後會顯示您的 LINE 顯示名稱和綁定時間

### 解除綁定

若需更換 LINE 帳號：
1. 前往個人設定頁面
2. 點擊「解除綁定」按鈕
3. 確認解除後，可重新綁定其他 LINE 帳號

---

## 2. LINE Bot 對話式回報

### 啟動回報

在 LINE 對話視窗中輸入：
```
回報問題
```

系統會開始引導您填寫回報單。

### 完整流程（8 步驟）

#### 步驟 1: 輸入問題標題
- 系統提示：「請輸入問題標題（最多 50 字）：」
- 範例：`網站登入異常`

#### 步驟 2: 輸入問題內容
- 系統提示：「請輸入問題內容（最多 150 字）：」
- 範例：`無法使用帳號密碼登入，顯示「伺服器錯誤」訊息`

#### 步驟 3: 選擇所屬單位
- 系統顯示按鈕選單（最多 13 個選項）
- 點擊對應的單位按鈕（例：「資訊部」）

#### 步驟 4: 選擇緊急程度
- 🟢 **低**: 可於正常工作時間處理
- 🟡 **中**: 需於當日處理
- 🔴 **高**: 需立即處理

#### 步驟 5: 輸入聯絡人姓名
- 系統提示：「請輸入聯絡人姓名：」
- 範例：`王小明`

#### 步驟 6: 輸入聯絡電話
- 系統提示：「請輸入聯絡電話（例：0912-345-678 或 02-12345678）：」
- 格式：
  - 手機：`09xx-xxx-xxx` 或 `09xxxxxxxx`
  - 市話：`0x-xxxx-xxxx` 或 `0xxxxxxxxx`

#### 步驟 7: 確認送出
- 系統顯示回報資訊摘要
- 三個選項：
  - ✅ **確認送出**: 建立回報單
  - 🔄 **重新填寫**: 清空所有欄位，重新開始
  - ❌ **取消**: 中止回報流程

#### 步驟 8: 完成
- 系統回覆：
  ```
  ✅ 回報成功！
  
  回報單編號：1234
  查看詳情：https://your-domain.com/callrecord/1234
  ```

### 中途取消

在任何步驟輸入：
```
取消
```
系統會立即中斷流程並清除暫存資料。

### 常見問題

#### Q: 輸入錯誤怎麼辦？
**A**: 
- 對話進行中：系統會要求重新輸入（例：電話格式錯誤）
- 已到確認步驟：點擊「重新填寫」按鈕
- 送出後：請聯絡處理人員或管理員修改

#### Q: 對話進行到一半斷線了？
**A**: 對話會保留 **5 分鐘**。5 分鐘內可繼續輸入，超過時間需重新輸入「回報問題」啟動。

#### Q: 為什麼提示「選項過多，請至網頁端回報」？
**A**: 系統的詢問單位超過 13 個，LINE 無法顯示完整選單。請改用網頁版新增回報單。

#### Q: 提示「尚未綁定系統帳號」怎麼辦？
**A**: 請先完成「綁定 LINE 帳號」步驟（見第 1 節）。

## 3. 接收即時通知

### 誰會收到通知？

當系統建立新回報單時：
- ✅ **已綁定 LINE 的處理人員** 會收到 Flex Message 通知
- ❌ **未綁定 LINE 的處理人員** 不會收到（需至網頁查看）

### 通知內容

Flex Message 包含：
- 📋 **詢問系統**: 問題所屬單位
- 📝 **主旨**: 問題標題
- 🚨 **緊急度**: 🟢低 / 🟡中 / 🔴高
- 👤 **聯絡人**: 姓名
- 📞 **電話**: 聯絡方式
- 🔗 **查看詳情**: 點擊按鈕開啟網頁詳情頁

### 通知時機

- ✅ 網頁端新增回報單 → 立即發送
- ✅ LINE Bot 新增回報單 → 立即發送
- ❌ 修改回報單狀態 → **不發送**（目前版本）

## 系統限制與注意事項

### 對話中斷情況

以下情況會導致對話中斷，需重新啟動：
1. ⏰ **5 分鐘無回應** - 自動清除對話狀態
2. 🔧 **系統維護重啟** - 所有對話立即中斷（通常在非工作時段）
3. ❌ **主動取消** - 輸入「取消」指令

### 重要提醒

- ⚠️ 系統維護期間可能中斷對話，建議**工作時段內一次完成回報**
- ⚠️ 對話中斷不會影響已送出的回報單，僅遺失未完成的暫存資料
- ⚠️ 建議在 5 分鐘內完成回報，避免逾時重新填寫

### 資料安全

- 🔒 LINE Webhook 使用 HMAC-SHA256 簽章驗證，防止偽造訊息
- 🔒 僅已登入且綁定的使用者可使用 LINE Bot
- 🔒 對話內容僅暫存於系統記憶體，不會永久儲存（除非送出建立回報單）

## 技術支援

若遇到以下問題，請聯絡系統管理員：
- 綁定失敗（顯示「此 LINE 帳號已被其他使用者綁定」）
- 通知未收到（處理人員已綁定但無通知）
- 對話異常中斷（非逾時或取消情況）
- 回報單編號顯示但網頁查不到
