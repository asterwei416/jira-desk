# Feature Spec Review Checklist

- [ ] Spec describes a single feature, not a system
- [ ] Scope is clearly limited
- [ ] Out of scope is explicitly listed
- [ ] No future or roadmap content included
- [ ] No system-wide architecture described
- [ ] Relationship to existing features is present
- [ ] Builds upon / Depends on / Does not modify are all filled
- [ ] No implicit modification of other features
